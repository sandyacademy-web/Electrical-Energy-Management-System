02 · Data Sources

Sumber Data EEMS

Data Center menerima data dari modul-modul utama EEMS serta sumber data sistem yang telah dikendalikan.

MODULE · 01

Corporate

Data kebijakan, organisasi, sasaran, dan informasi pengelolaan perusahaan.

  • Organization
  • Policy
  • Management Requirement
MODULE · 02

Electrical

Data kondisi, pengukuran, beban, keandalan, dan status sistem kelistrikan.

  • Voltage / Current
  • Load / Power
  • Availability
MODULE · 03

Energy

Data konsumsi, performa, efisiensi, biaya, dan penghematan energi.

  • Energy Consumption
  • Energy Cost
  • Energy Performance
MODULE · 04

Maintenance

Data pemeliharaan, pekerjaan, kondisi aset, backlog, dan keandalan.

  • Work Order
  • Maintenance Status
  • Asset Reliability
MODULE · 05

HSE / K3

Data risiko, keselamatan, inspeksi, insiden, dan tindakan korektif.

  • Risk
  • Incident / Near Miss
  • Corrective Action
MODULE · 06

Project

Data lingkup, jadwal, biaya, progress, risiko, kualitas, dan penyelesaian proyek.

  • Progress
  • Schedule
  • Budget / Cost
MODULE · 07

Finance

Data anggaran, biaya aktual, komitmen, invoice, dan penyimpangan biaya.

  • Budget
  • Actual Cost
  • Variance
MODULE · 08

Human Resources

Data personel, kompetensi, pelatihan, otorisasi, dan kinerja.

  • Manpower
  • Competency
  • Training / Authorization
CONTROL · 05

Master Data

Data referensi utama yang memastikan konsistensi objek di seluruh sistem EEMS.

  • Asset
  • People / Location
  • Vendor / Parameter
03 · Data Center Functions

Fungsi Data Center

Data Center mengendalikan perjalanan data dari sumber sampai menjadi informasi yang dapat digunakan.

DC-01

Data Collection

Mengumpulkan data dari modul, sistem, perangkat pengukuran, dan sumber data yang telah ditetapkan.

DC-02

Data Validation

Memeriksa kelengkapan, format, validitas, konsistensi, dan kewajaran data.

DC-03

Data Integration

Menghubungkan data antar-modul sehingga informasi tidak berdiri sendiri.

DC-04

Data Processing

Mengolah data menjadi agregasi, tren, indikator, perbandingan, dan informasi.

DC-05

KPI Engine

Mengelola definisi, sumber, formula, target, actual, variance, dan status KPI.

DC-06

Monitoring Engine

Menyediakan status kondisi, exception, indikator perhatian, dan informasi monitoring.

DC-07

Data Quality

Mengendalikan kualitas data agar informasi yang dihasilkan dapat dipercaya.

DC-08

Information Consolidation

Mengonsolidasikan informasi lintas fungsi untuk kebutuhan manajemen.

DC-09

Information Output

Menyalurkan informasi menuju Dashboard, Management Report, dan kebutuhan analisis.

10 · Responsibilities

Tanggung Jawab Data

Data Center tidak menggantikan pemilik data. Setiap fungsi tetap bertanggung jawab atas data yang dihasilkan dan kualitasnya.

Data Owner

Bertanggung jawab atas kebenaran dan substansi data pada fungsi masing-masing.

Data Controller

Mengendalikan validasi, kualitas, status, dan konsistensi data.

Data Administrator

Mengelola struktur, akses, konfigurasi, dan administrasi data sistem.

KPI Owner

Bertanggung jawab atas definisi, target, interpretasi, dan penggunaan KPI.

Management

Menggunakan informasi sebagai dasar evaluasi, keputusan, dan tindakan manajemen.

System Control

Menjaga integritas proses pengendalian, traceability, dan kepatuhan sistem.

11 · Data Principles

Prinsip Data EEMS

ACCURATE Data harus benar dan dapat dipertanggungjawabkan.
VALID Data harus memenuhi aturan dan kriteria validasi.
CONSISTENT Data harus konsisten antar fungsi dan periode.
TRACEABLE Data harus dapat ditelusuri ke sumbernya.

Data Menjadi Informasi.

Data Center menyediakan fondasi informasi yang menghubungkan seluruh modul EEMS dengan Dashboard, KPI, Monitoring, dan Management Report.
